# Codebrain.me
Site statique HTML/CSS/JS, prêt pour GitHub Pages.

## À personnaliser
- Remplacer les liens Discord `https://discord.gg/` par l'invitation réelle.
- Ajouter `assets/og-codebrain.jpg` (1200×630) pour la preview Discord principale.
- Remplacer/compléter les projets et liens vidéo dans `script.js`.
- Le bloc live est statique par défaut : pour un vrai statut Twitch automatique, il faudra passer par une API/Worker afin de ne pas exposer de secret Twitch dans le front.
- Créer au besoin `/portfolio/` et `/ct/` avec leurs propres balises Open Graph pour des previews Discord spécifiques.
